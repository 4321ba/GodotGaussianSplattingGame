# GodotGaussianSplattingGame

This project is for a university project laboratory. The goal is to make GodotGaussianSplatting more integrated into the editor: be able to move multiple objects around, as we are able to do with regular meshes. This branch has the documentation, and a car racing project integrated. For the master thesis project, that is a more flexible Godot addon based on these projects, see [this](https://github.com/4321ba/GodotGaussianSplattingNodes) repository.

The documentation can be found [here](https://github.com/4321ba/GodotGaussianSplattingGame/blob/vitavehicle/documentation/documentation.md).
